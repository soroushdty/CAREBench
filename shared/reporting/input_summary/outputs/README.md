# CAREBench Summary Outputs

**Canonical path:** `shared/reporting/input_summary/outputs`

This directory is responsible for the actual formatting and generation of the visual (plots) and tabular (CSV) summary artifacts. It consumes the processed data generated by the `logic` modules and writes them out safely.

## Core Modules

### `stage_outputs.py`
Iterates through all permutations of dataset Stages (Raw, Standardized, Final, etc.) and Splits (Train, Test, Interview), generating granular artifacts for each:
- **Class Distributions**: Bar plots and CSVs of positive class frequencies.
- **Class Co-occurrence**: Heatmaps visualizing label correlations.
- **Label Cardinality**: Analysis of how many concurrent positive labels a single row possesses.
- **Text Length**: Histograms bounding word counts in the textual item descriptions.
- **Duplicate Profiling**: Scans and flags exact row or patient/item triplet duplicates.
- **Item Frequency**: Counts vocabulary frequencies before and after standardization.

**Generated Files in `preprocessing_stages/<stage>/<split>/`:**

| File                                     | Description                                                                                 |
| ---------------------------------------- | ------------------------------------------------------------------------------------------- |
| `missing.csv`                            | Missing values by column — count and percent                                                |
| `patient_distribution.csv`               | Row count and percent share per patient                                                     |
| `class_distribution.csv`                 | Positive count and prevalence percent per label                                             |
| `class_cooccurrence.csv`                 | Label-by-label co-occurrence matrix                                                         |
| `text_length.csv`                        | Binned word-count histogram with summary statistics (median, mean, std, min, max)           |
| `per_patient_class_count.csv`            | Per-patient row count and summed class values                                               |
| `per_label_patient_positive_buckets.csv` | Per-label patient buckets: zero, exactly 1, 2, 3, 4, and fewer than 5 positives             |
| `fractional_label_audit.csv`             | Binary vs fractional value audit per label                                                  |
| `fractional_values.csv`                  | Observed non-binary values and their counts                                                 |
| `duplicate_profile.csv`                  | Duplicate row and grouping diagnostics                                                      |
| `duplicate_samples.csv`                  | Sample duplicate rows for inspection (always written; body is empty if no duplicates exist) |
| `label_cardinality.csv`                  | Labels-per-row distribution and summary percentages                                         |
| `rows_per_patient.csv`                   | Row-count distribution per patient                                                          |
| `labels_per_patient_summary.csv`         | Per-patient label totals and class-level sums                                               |
| `item_frequency_raw.csv`                 | Item frequency table — raw stage                                                            |
| `item_frequency_standardized.csv`        | Item frequency table — standardized stage                                                   |

### `final_outputs.py`
Responsible for dumping any top-level summary diagnostics specifically belonging to the finalized dataset payload (e.g., final distributions independent of the intermediate staging artifacts).

### `notes_outputs.py`
Generates human-readable metadata, including an automatically constructed JSON `summary_index` and a markdown/text trace of the exact settings configuration used to run the pipeline, aiding future reproducibility.
